## 3. 合成数据实验链（P0-P5）

### 主表

| 实验 | F1 | halluc | omit | format% | 说明 |
|---|---|---|---|---|---|
| B0 零样本 | 0.000 | 0 | 1002 | 0% | 格式失败 |
| B1 SFT | 0.932 | 59 | 65 | 99.8% | 格式习得 |
| B2 TAC (w=5) | 0.935 | 55 | 63 | 100% | 时间精度最优 |
| B3 统一 | 0.902 | 198 | 140 | 99.6% | 复杂退化 |
| B3-permuted | 0.913 | 137 | 117 | 99.6% | 排列不变 |
| B3-slot-aware | 0.926 | 99 | 87 | 99.6% | 计数+slot |
| B3-slot-aware-5k | 0.948 | 46 | 54 | 100% | 数据规模化 |
| B3-CARC | 0.912 | 57 | 118 | 100% | 幻觉-71% |
| B3-CARC-5k | 0.920 | 67 | 94 | 100% | CARC 大数据退化 |
| DPO 保守 | 0.951 | 48 | 52 | 100% | 微幅提升 |
| P5 oracle | 0.890 | 11 | 11 | — | 完美分离上界 |
| P5 predicted | 0.270 | 32 | 28 | — | 分离级联-70% |

### 关键发现

1. **B0→B1→B2**：格式习得 + 时间精度（w=5 最优）
2. **B2→B3**：复杂退化（hallucination 55→198）
3. **B3→slot→slot-5k**：排列不变+计数+规模化（F1 0.902→0.948，幻觉 -77%）
4. **CARC**：小数据幻觉 -71%，大数据退化（正则化工具）
5. **DPO**：保守设置微幅提升（+0.3pp），激进设置格式崩溃
6. **P5**：分离级联惩罚 -70%，**隐式 > 显式**

## 4. 真实音频实验链（v6k/v7/v8）

### 数据管道演进

| 版本 | 音源 | Caption | 时间戳 | 场景 |
|---|---|---|---|---|
| v1 | ESC-50 随机 | MOSS 逐源 | 放置位置 | 随机 |
| v6 | ESC-50 + GTZAN + MOSS demo | MOSS 逐源 | 放置位置 | 12 模板 |
| v6k | v6 + 1000 条 | v6 简单 prompt | 放置位置 | v6 |
| v7 | v6 + 1000 条 | 增强 prompt | RMS 活跃区间 | v6 + 场景限制 |
| v8 | v6 + 1000 条 | v6 简单 prompt | RMS 活跃区间 | v7 |

### 关键发现

1. **真实音频 > 合成音频**：v6k F1=0.970 > 合成 5k F1=0.948
2. **200→1000 条提升 speech**：speech F1 0.875→0.952（+7.7pp）
3. **固定时间戳改善 onset-MAE**：v8 0.154s（vs v6k 0.262s）
4. **增强 prompt 改善 speech**：v7 speech F1=1.0
5. **但固定时间戳+增强 prompt 损害整体 F1**：v7/v8 < v6k

## 6. 论文叙事链

```
合成数据验证（P0-P5）：
B0(0.000) → B1(0.932) → B2(0.935) → B3(0.902) → slot(0.926) → slot-5k(0.948)
→ CARC(幻觉-71%) → DPO(0.951) → P5(隐式>显式)

真实音频验证（v6k/v7/v8）：
合成 5k(0.948) → 真实 v6k(0.970) → v7(speech=1.0) → v8(onset=0.154s)
```

### 核心贡献

1. **Track-Event Ledger 格式**：模型学会结构化事件检测
2. **Slot-aware 训练**：排列不变 + 事件计数，幻觉 -77%
3. **CARC 反事实一致性**：小数据幻觉 -71%
4. **隐式 > 显式分离**：mixture trained (0.970) >> Demucs cascade (0.270)
5. **真实音频管道**：ESC-50 + GTZAN + MOSS caption = F1=0.970
