### 检索确认的关键链接（相比 docs/24 的增量与修正）

1. **TACOS**：GitHub `https://github.com/OptimusPrimus/tacos`（注意与 `FlagOpen/TACO`、`BAAI/TACO` 代码数据集不同，检索易混淆）；Zenodo `https://zenodo.org/records/15379789`；HF 论文页 `https://huggingface.co/papers/2505.07609`。
2. **FSD50K**：Zenodo `4060432`；HF 镜像 `philgzl/fsd50k`（已转 Opus 减体积）；ModelScope `OmniData/FSD50K`。
3. **OpenSLR 编号确认**：LibriSpeech=SLR12、MUSAN=SLR17、RIR_NOISES=SLR28、AISHELL-4=SLR111、AliMeeting=SLR119。HF 官方 org `openslr` 有镜像（`openslr/librispeech_asr`）。
4. **AudioTime 定位修正**：官方入口是 **PicoAudio 仓库 `zeyuxie29/PicoAudio`**（论文 arXiv 2407.02869），但**未检索到独立 Zenodo/HF dataset 直链**，需在 README 核实数据获取方式（docs/25 §8 已标注）。
5. **中文歌声**：Opencpop=`wenet-e2e/opencpop`、M4Singer=`M4Singer/M4Singer` + HF `umoubuton/m4singer`、OpenSinger 见 `open-mmlab/Amphion` Sing-0.4k。
6. **RIR/噪声**：SLR28 有 HF 镜像 `schism-audio/openslr-rirs`；MUSAN SLR17；BUT ReverbDB、MIT IR Survey、ACE Challenge。
7. **DESED/FUSS**：DESED 官网 `project.inria.fr/desed/download` + GitHub `turpaultn/DESED`；FUSS Zenodo `3743844`（单源+混合+GT stems，适合 CARC）。
8. **MUSDB18** 补充 ModelScope 镜像 `OmniData/MUSDB18`；MoisesDB HF `wearemusicai/moisesdb`；jamendolyrics HF `jamendolyrics/jamendolyrics`。

### 环境约定（已在 MEMORY.md 固化）
- 素材根目录 `data/sources/`，**禁用 `/tmp`**；`HF_HOME` 也不得指向 `/tmp`。
- 国内用 `HF_ENDPOINT=https://hf-mirror.com`。
- 下载后 `find ... -exec sha256sum` 写 `SOURCES.sha256`。
