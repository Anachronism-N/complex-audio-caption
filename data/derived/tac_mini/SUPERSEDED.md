# Superseded TAC-mini artifact

The checked-in 500-row manifest was generated by renderer v0.2 and is retained only to audit historical B0 results. Do not use it for B1/B2 training.

Known defects:

- every row lacks the `__residual__` component required to reconstruct post-echo/mastered mixtures;
- `mix_000028` and `mix_000055` contain duplicate speech/SFX source IDs;
- coarse 0.5/1.0-second activity masks produced incorrect overlap ratios;
- persisted WAV byte hashes were not recorded.

Regenerate renderer v0.3 artifacts with:

```bash
python -m sceneledger.cli.render \
  --config configs/data/tac_mini.yaml \
  --output-dir /tmp/tac_mini_v2 \
  --validate
```

The new output must pass `sceneledger.cli.prepare_moss_sft` without `--allow-invalid-manifest` before training.
